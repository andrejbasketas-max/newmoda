---
name: glavonja-settings
description: Show or change GLAVONJA AI STUDIO settings (language, duration, Gemini, Flow, research keys, audio). Use for /glavonja-settings.
---
`python glavonja.py settings` (keys are masked) · change: `python glavonja.py settings <dotted.key> <value>`
e.g. `settings language en`, `settings target_duration_sec 480`, `settings audio.music_volume_db -22`.
Never print or commit API keys. Prefer the dashboard Settings for keys.
