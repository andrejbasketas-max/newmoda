# Asset & software licences

Every asset added by the studio is also recorded in the database table `assets_license`, and every
Google-generated asset in `database/asset_license.json`.

| Item | Licence / terms | Notes |
|---|---|---|
| Studio source code | written for the channel owner | |
| DejaVu Sans fonts (`assets/fonts`) | Bitstream Vera / DejaVu licence (free redistribution) | `assets/fonts/DejaVu-LICENSE.txt` |
| Character, props, backgrounds | procedurally generated by this code | own work |
| Music + sound effects | synthesised by `studio/audio.py` (NumPy) | own work, no third-party samples |
| FFmpeg (BtbN GPL build) | GPL | downloaded by install.bat into `tools/`, not modified |
| espeak-ng via espeakng-loader | GPL-3 | fallback voice only |
| Piper TTS | MIT (engine); each voice model has its own licence (see model card) | fallback voice only |
| Gemini TTS audio | Google Generative AI terms of your account | recorded per file |
| Google Flow clips | Google Generative AI / Flow terms of your account | recorded per file |
| Reference frames from your channel | your own content | used only locally for comparison |

Do not add music or sound effects downloaded from the internet unless their licence allows YouTube use.
Record them in `docs/LICENSES.md`.
