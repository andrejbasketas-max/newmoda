# Claude Code skills

The skills live in `.claude/skills/` (that is where Claude Code loads them when you open this folder):
`/glavonja-ideas`, `/glavonja-make`, `/glavonja-status`, `/glavonja-continue`, `/glavonja-style`,
`/glavonja-settings`, `/glavonja-history`.

Each skill only calls `glavonja.py`. The same commands work in the dashboard command box without Claude Code.
